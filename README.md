# it-security-review — Claude Code Skill

社員が申請したソフトウェア・SaaS・クラウドサービスの **社内利用可否をIT/セキュリティ統制の観点から調査・評価** する Claude Code スキルです。

Web検索で一次情報（プライバシーポリシー・セキュリティホワイトペーパー・第三者認証）を収集し、**6分野18項目のチェックリスト** に基づく3段階リスク評価付きの日本語 Markdown レポートと、**稟議システムの承認コメント欄にそのまま貼れる短文サマリー** を自動生成します。

---

## できること

- 対象サービスをWeb検索で **リアルタイム調査**（学習データの記憶だけに頼らない）
- **6分野18項目**（運営体制・データ保護・データ所在地・アクセス管理・外部認証・AI機能）を網羅的にチェック
- 各項目を **🟢 低 / 🟡 中 / 🔴 高** の3段階でリスク評価
- 総合判定（**推奨 / 条件付き許可 / 非推奨**）と判定理由を生成
- 社内運用ルール（MFA必須・AI学習オプトアウト等）を具体的に提示
- **稟議用の承認コメント案**をコードブロックで出力（そのままコピー&ペースト可）
- 複数サービスの比較評価・比較サマリー表の生成にも対応

### 出力イメージ

```
# ソフトウェア安全評価レポート：[サービス名]

- 評価実施日: 2025-XX-XX
- 評価対象プラン: Business プラン
- 想定用途・データ区分: 社内限定情報の取り扱いを想定

## 1. 総合評価
判定結果: 🟡 条件付き許可

## 2. セキュリティ項目別チェック一覧
| 評価項目         | 調査結果・事実                  | リスク評価 |
| :---             | :---                            | :---       |
| 運営企業・所在地 | 米国法人、NYSE上場              | 🟢 低      |
| インシデント履歴 | 調査時点で重大インシデントなし  | 🟢 低      |
| ...              | ...                             | ...        |

## 6. 申請用 承認コメント案
【情報システム部門セキュリティ評価済（2025/XX/XX）】判定: 🟡 条件付き許可
...
```

## インストール

### 方法 A：`.skill` ファイルから直接インストール（推奨）

1. [`it-security-review.skill`](./it-security-review.skill) をダウンロード
2. Claude Code で実行：

```bash
claude skill install ~/Downloads/it-security-review.skill
```

### 方法 B：ソースから手動配置

```bash
mkdir -p ~/.claude/skills/it-security-review/references
cp SKILL.md ~/.claude/skills/it-security-review/
cp references/*.md ~/.claude/skills/it-security-review/references/
```

## 使い方

インストール後、Claude Code に以下のように話しかけるだけで起動します。

### トリガーフレーズ例

```
〇〇のセキュリティ評価をして
〇〇は社内で使っても大丈夫？
このSaaSのセキュリティチェックをして
新しいツールの導入審査をして
〇〇と△△どちらが安全？
```

「セキュリティ」という言葉がなくても、**特定ツールの社内導入可否・利用申請・リスク判断**が話題になれば自動で起動します。

### 評価の流れ

```
1. 前提確認（対象サービス名・利用プラン・想定データ区分）
   └ プランが不明な場合のみ1回確認。回答がなければ Business/Enterprise 相当で評価

2. Web調査（公式サイト・Trust Center・認証機関の登録簿・インシデント報道）

3. 6分野18項目のチェックリスト評価

4. レポート生成（Markdown ファイル）+ 承認コメント案の出力
```

### 評価対象の例

- 社員から利用申請のあった業務 SaaS（Notion、Figma、ChatGPT Teams 等）
- 新規導入を検討しているクラウドサービス
- 複数候補の比較検討（「AとBどちらを採用すべきか」）

---

## 評価チェックリスト概要

| 分野 | 評価項目 |
|------|---------|
| A. 運営体制 | 運営企業・所在地、インシデント履歴、政府開示義務、事業継続性、サポート体制 |
| B. データ保護 | 規約・HTTPS、学習利用とオプトアウト、暗号化、データ削除・エクスポート |
| C. データ所在地 | 保存サーバー国・地域、保管国の選択可否、最終的な所在 |
| D. アクセス管理 | パスワードポリシー、MFA/SSO 対応、操作ログの取得 |
| E. 外部認証 | ISMS/ISO 27001、SOC 2、Pマーク等の取得状況 |
| F. AI機能 | AI機能の有無・学習利用、外部送信先・保持期間・自律行動リスク |

詳細な評価基準は [`references/checklist.md`](./references/checklist.md) を参照してください。
